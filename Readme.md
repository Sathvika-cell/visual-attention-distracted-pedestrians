# Visual Attention Behaviour of Distracted Pedestrians

This project analyzes pedestrian situational awareness and gaze behaviour under different distraction conditions using eye-tracking data and virtual pedestrian simulation.

## Project Overview
The study evaluates how distractions such as texting, phone calls, music, and billboard interaction influence pedestrian visual attention during road crossing scenarios under:
- Illuminated Crosswalk (IC)
- No Countermeasure (NO_CM)

## Features
- Eye-tracking data extraction and preprocessing
- Condition-wise data merging and transformation
- AOI (Area of Interest) categorization
- Fixation count and fixation duration analysis
- Comparative analysis across distraction conditions
- Pedestrian situational awareness evaluation

## Repository Contents

- Python

## Key Insights
- Illuminated Crosswalks improved focus on safety-critical road elements
- Mobile-based distractions increased cognitive load and gaze fragmentation
- Infrastructure-based visual cues helped reduce distraction impact
